Une cliente nous signale un problème, son mail est dans `signalement.md`. Le code de l'outil de facturation est dans `projet/`.

1. Reproduis le problème.
2. Trouve la cause et corrige-la, sans casser le reste.
3. Ajoute un test qui aurait attrapé ce bug, puis lance tous les tests (`python3 -m unittest` dans `projet/`) et montre qu'ils passent.
4. Écris dans `reponse.md` la cause en une phrase, ce que tu as changé, et la réponse à envoyer à la cliente.
